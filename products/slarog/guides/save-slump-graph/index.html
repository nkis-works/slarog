SLAROG GUIDE / SAVE

スランプグラフを保存して、あとから見返せる記録にする。

スクリーンショットを残すだけでも画像は保存できます。ただ、枚数が増えると「いつ・どの店・どの機種・何番台か」が分からなくなり、同じ台の過去記録も探しにくくなります。ここでは、画像を比較しやすい記録として残すための基本を整理します。

保存するときに、画像と一緒に残したい情報

あとから見返す前提なら、グラフ画像だけでなく識別情報をそろえておく方が実用的です。スラログでは、日付・店舗・機種・台番号を記録に付けて保存できます。

  • 日付：いつの営業日のグラフか
  • 店舗：どのホールの記録か
  • 機種：同名シリーズの取り違えを防ぐ
  • 台番号：同じ機種が複数台ある場合に区別する

この4項目がそろうと、同じ台の過去記録を探したり、後から複数日を連結したりしやすくなります。

スクリーンショットと撮影画像は、どちらでも使える

データサイトをスマートフォンで見ている場合はスクリーンショット、店内のデータ表示機を記録する場合は撮影画像が元になります。どちらの場合も、グラフの表示範囲、ゼロ線、目盛りが確認できる状態が扱いやすいです。

撮影画像は、斜めから撮ると縦方向の尺度が場所によって変わって見えるため、できるだけ正面から撮影します。反射や人物、店舗・台を特定できる情報の扱いにも注意し、店舗のルールに従ってください。

スラログで保存する基本手順

  1. 「作成」から元のスランプグラフ画像を読み込む
  2. グラフの表示範囲と位置を合わせる
  3. ゼロ線と目盛り間隔を合わせる
  4. グラフ線を記録する
  5. 日付・店舗・機種・台番号を登録して保存する

保存後はアーカイブやカレンダーから過去の記録を確認でき、同じ条件の記録が複数あれば連結して見ることもできます。

表示期間が短いサイトほど、保存する意味が大きい

直近数日だけを表示するデータサイトでは、新しい日が加わると古い日が表示範囲外になります。後から前週や前月の動きを見たい場合、表示期間内に必要な記録を残しておく必要があります。

単に「大きく出た日」だけを残すと、比較が偏ります。上昇しなかった日、途中で失速した日も同じ基準で保存すると、後から記憶や印象と実際の記録を照合しやすくなります。

保存したグラフで分かること・分からないこと

保存した記録から、過去の形、最高点や最低点の位置、複数日にわたる推移などを振り返れます。一方で、保存した形そのものから設定、内部状態、次の出玉推移を確定することはできません。

記録と予測は分けて扱う スラログは、画像を保存・整理・連結して比較するための記録アプリです。勝敗、設定、将来結果を保証するものではありません。

画像を、あとから探せる記録として残す

スラログはiOS・Androidで公開しています。保存した記録を日付・店舗・機種・台番号ごとに整理し、必要に応じて複数日を連結できます。
