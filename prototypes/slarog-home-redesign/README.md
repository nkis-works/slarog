# スラログ トップページ再設計比較

このディレクトリは、現行 `index.html` を変更せずに比較するための非公開プロトタイプです。`feature/slarog-home-redesign-prototypes` のCloudflare previewでだけbuild対象になり、通常previewとproduction buildには含まれません。

## 現行が企業的に見える理由

- NKIS Worksを先頭に置くヘッダーと6件ナビが、スラログを企業の製品の一つに見せている。
- ヒーローの疑似ブラウザ枠、情報カード、2面比較、同型機能ブロックが、営業資料のような構成を作っている。
- 文章と実画面がすべて均一な囲みへ収納され、ユーザーの操作より「機能一覧」が先に見える。
- 中央揃えの大見出し、角丸、影、余白の反復により、テンプレート由来のSaaS LPらしさが強い。
- 現行の大型囲み要素は15件。A/Bでは大型角丸カードを0件にし、実画面・罫線・背景帯で流れを作った。

## A：編集記事・プロダクトストーリー型

- 困りごと、作った理由、実際の操作を読み物の順でつなぐ。
- 余白と罫線、左右にずらした実画面で編集記事のリズムを作る。
- 作り手の温度が最も伝わる一方、Bより操作の一覧性は少し低い。
- 実画面は11枚、7素材をすべて使用。

## B：実画面・操作フロー中心型

- ヒーローから3つの実画面を並べ、何をするアプリかを最短で伝える。
- 実画面は元画像の縦横比を固定し、舞台内で全体が見える大きさにする。
- 生成りの紙面、日本語明朝、欄外記号、罫線を使い、プロダクト紹介記事のようなリズムで見せる。
- 7段階の操作を番号付きの連続レイアウトで見せ、実用ツールとしての理解を優先する。
- 作った理由は操作の前に自然な読み物として置き、企業のMission表現にしない。
- NKIS Worksを独立したバッジや肩書きにせず、「作った理由」の本文でだけ自然に説明する。
- 料金はプラン比較に見える横並びや青い価格パネルをやめ、手元の画像で試してから続ける流れを案内紙のように伝える。
- ヘッダーはプロダクト名と用途だけに絞り、NKIS Worksは機能説明より前の「作った理由」で紹介する。
- 実画面は11枚、7素材をすべて使用。

## 個人プロダクトサイトのリサーチ

- [Bondavi](https://bondavi.jp/works)：困りごとを先に置き、開発秘話へつなぐ日本語の距離感を参考にした。
- [PenCake](https://pencake.app/ja/)：静かな余白と文字組み、実画面より強い装飾を置かない姿勢を参考にした。
- [minical](https://minical.app/)：プロダクト名、短い用途説明、実画面へ絞った導入を参考にした。
- [MoneyNote](https://moneynote.komorebi-apps.com/)：具体的な日本語と実画面を結び付ける構成を参考にした。
- [AppVillage](https://www.app-village.jp/)：生成り、明朝、罫線を使った編集記事らしい温度感を参考にした。
- [Indie App Hub](https://i-apphub.space/)：日本語一文で役割を明示し、情報量を抑える構成を参考にした。

詳しい採用・不採用理由は [`JAPANESE_PRODUCT_SITE_RESEARCH.md`](./JAPANESE_PRODUCT_SITE_RESEARCH.md) に記録した。

B案では、ヘッダーから作り手名を外して用途表示へ変更し、独立した作り手バッジを置かず、作った理由を操作フローより前へ移動した。料金は価格カードではなく、試してから続けるか決める一続きの文章にした。レビュー数、導入実績、比較表、派手な実績バッジは事実確認できず企業LP感も強くなるため採用していない。

## 推奨

**B案を推奨する。** 目標比率の「実用ツール感50%」を最も満たし、5秒で用途を理解しやすい。A案の温度感は魅力だが、今回の最優先である「実画面を主役にする」「機能を使う順番で理解する」ではBが明確に強い。Bの作った理由と正式ページへの導線により、個人ブログ化せず信頼感も保てる。

## 共通の契約

- 主役は「スラログ」。A案は `by NKIS Works`、B案は「作った理由」の本文でNKIS Worksとの関係を示す。
- ヘッダーナビは4件。
- 14日間無料、その後は月額380円。
- 非公開案では「無料体験終了後は月額380円で自動更新」「App Store／Google Playのアカウント管理から解約」を表示。
- 税込表示はストア設定確認後に確定する旨を明記。
- 設定判別、勝敗、利益、将来結果を保証・推奨しない。
- 英語装飾ラベルは0件。許可されたブランド補助の `by NKIS Works` だけを残す。
- 外部通信、広告、Analytics、Cookie、localStorage、sessionStorage、IndexedDBを使用しない。
- A/Bとも大型角丸カード0件（現行15件から100%削減）。料金は背景帯、FAQは罫線で表現する。
