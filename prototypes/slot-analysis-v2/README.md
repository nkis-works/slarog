# スロット出玉分析 v2 — 非公開設計プロトタイプ

このディレクトリは、情報設計、文言、レスポンシブ、キーボード操作を確認するための**非公開設計プロトタイプ**です。本番ロジック、本番URL、本番ビルドの一部ではありません。

## 確認できる状態

- `index.html`: 推奨する縦リスト型のクイック入力・結果。
- 基準100/103/105%の比較選択。
- 目標逆算、区間直接/累積入力、投資・回収の段階開示。
- スラログCTAと、その後に置く将来の手動広告位置。
- 計算式、使い方、FAQ。
- `result-variants.html`: 横レールと縦リストの比較。
- 390×844pxの初期viewportにH1、一文、2入力、`出玉率を見る`までを収める設計。

## 境界

- 外部CDN、Web font、画像、API、広告、解析を使いません。
- Cookie、localStorage、sessionStorage、IndexedDBを使いません。
- URLのquery/hashに入力値を含めません。
- 計算コードは設計確認用で、既存の本番domain engineの代替ではありません。
- `scripts/build-site.mjs` の公開allowlist外です。

## ローカル表示

```sh
python3 -m http.server 4175 --directory prototypes/slot-analysis-v2
```

`http://127.0.0.1:4175/` を開きます。ファイル直開きでも基本表示できますが、検証はHTTP経由を推奨します。

## 代表値

`4,000G`、`+500枚`:

- 実績出玉率 104.2%
- +125枚/1,000G
- 「計算条件を見る」内に想定IN 12,000枚、想定OUT 12,500枚
- 100%基準 +500枚
- 103%基準 +140枚
- 105%基準 −100枚

## 注意

表示される「将来の手動広告位置」は設計境界を示すプレースホルダーで、広告コードでも広告枠の予約でもありません。実装判断は `docs/slot-analysis-v2/12_AD_MONETIZATION_SPEC.md` に従います。
