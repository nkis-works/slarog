# 発見した不整合

## 高

- サポートのH1・メタ・問い合わせ項目がスラログ専用で、Webツールの利用者が必要情報を判断できなかった。
- トップ、サポート、利用規約のWebツール説明が旧仕様の「差枚・投資・IN／OUT」を中心にしていた。
- ツールからスラログへのCTAが「手入力」と説明し、画像からグラフを作成する実機能と食い違っていた。

## 中

- プライバシーと利用規約のメタ情報が本文の適用範囲より狭く、検索結果ではスラログ専用に見えた。
- 目標逆算と区間比較に「数学上の境界」「寄与」等の専門語が残っていた。
- 「好調区間／低調区間」が、選択基準との差以上の意味を持つように読めた。
- 404に新ツールへの復帰導線がなかった。
- 現在ページのactive状態が一貫していなかった。

## 低

- `IN/OUT`、`IN / OUT`、`OS / 端末名`、`App Store / Google Play`が混在していた。
- 数値表示で `+2000枚`、`1000枚`など桁区切りが揃っていなかった。
- common footerが法務・サポートページでもスラログだけを説明していた。

## 矛盾がなかった項目

月額500円、無料プラン1台、期限なし、広告なし、有料プラン台数無制限、ストア準備中、iOS／Android対応予定、サポートメールは、確認した各ページ間で一致していた。
