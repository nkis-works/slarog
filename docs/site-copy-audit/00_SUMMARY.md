# サイト文言・情報整合性監査

## 結論

NKIS Works公式サイトと「スロット出玉分析」を、利用者がサービスの違いと現在の機能を迷わず理解できる表現へ統一した。スラログは、14日間無料体験・月額380円の単一料金導線へ改め、困りごと、作った理由、実際の画面が先に伝わる個人向けプロダクトページへ再構成した。

## 監査範囲

- トップ、サポート、プライバシーポリシー、利用規約、404
- スロット出玉分析、旧URL案内
- robots.txt、sitemap.xml
- 共通ヘッダー、モバイルメニュー、フッター、メタ情報
- TypeScriptで生成する結果、エラー、補足、live region
- source、preview build、production build、隔離preview

## 主な改善

- サポートをアプリ・Webツール共通の案内へ変更
- 問い合わせ情報へサービス名、ブラウザ、OS／端末情報を追加
- トップ、規約、プライバシーのツール説明を現行機能へ統一
- 「クイック結果」「数学上の境界」「寄与」等の内部寄り表現を一般向けに変更
- 「実IN／OUT」「App Store／Google Play」等の表記を統一
- スラログCTAを画像からグラフを作成する実機能と一致
- 旧料金案を廃止し、14日間無料体験・月額380円・ストアでの解約へ統一
- 料金比較表を単一の料金導線へ変更
- 利用者の困りごとと「作った理由」を追加し、実画面を使う順序に沿って配置
- 主要セクションの英語装飾見出しを日本語へ変更
- 現在ページを `aria-current="page"` で示し、404からツールへ到達可能に変更

## 維持した境界

無料体験期間と月額料金は確定事項に基づいて変更した。課金開始の具体的な条件、更新方法、税込表示はストア設定未確認のため断定していない。ストア公開状況、サポートメール、広告・解析・保存の実装状況と、設定判別、未来予測、続行判断を行わない境界は維持した。
