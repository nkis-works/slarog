# スラログ料金・プロダクトトーン変更

## 料金変更一覧

| 項目         | 旧案（廃止）           | 新しい確定表示                             |
| ------------ | ---------------------- | ------------------------------------------ |
| 利用開始     | 無料枠を期限なく利用   | 14日間無料体験                             |
| 無料期間中   | 1台まで                | 料金は発生しない                           |
| 継続利用料金 | 月額500円              | 月額380円                                  |
| 料金導線     | 無料枠と有料枠の比較   | 無料体験から月額利用へ進む1つの流れ        |
| 解約         | サブスクリプション案内 | App Store／Google Playのアカウント管理画面 |

一般公開文言から、無料プラン、1台まで、期限なし、月額500円、台数無制限、無料枠と有料枠の比較を削除した。過去資料では「旧案」「廃止」を明記した箇所だけに残している。

## 新料金表示

- 見出し：「まず14日間、使い心地を試せます。」
- 無料体験：14日間／¥0
- 体験終了後：月額¥380
- 無料体験中は料金が発生しない
- 解約は各ストアのアカウント管理画面から行う
- 課金開始、更新、税込表示は公開時のストア購入画面で確認する

ストア設定を確認できていないため、一般公開文言で「自動更新」や「税込」を断定していない。

## トーン変更前後

| 変更前                           | 変更後                                               |
| -------------------------------- | ---------------------------------------------------- |
| 機能一覧と料金比較が中心         | 利用者の困りごとと利用後の変化から開始               |
| 大型カードが連続する機能カタログ | 実画面を広く見せ、使う順序で説明                     |
| 英語kickerがセクションを先導     | 日本語見出しだけで内容を理解可能                     |
| 企業向けSaaSの2プラン比較        | 個人向けアプリの単一料金導線                         |
| 記録・比較の説明が抽象的         | 店舗・機種・台番号・日付、複数日の流れを具体的に説明 |

## 削除・縮小した企業的要素

- Before／After、Record & Review、Features、Plans、Coming Soonの英語装飾見出し
- 均一な大型機能カードの枠・背景
- 小さなポリシーチップの羅列
- 複数プランの比較カード
- 抽象的な営業資料風コピー

白・淡灰・青、余白、清潔感、法務・サポートの正式なトーンは維持した。

## 追加した「作った理由」

見出しは「グラフ画像を、あとで見返せる記録にしたかった。」とした。画像フォルダに記録が増え、店舗・機種・台番号・日付や同じ台の複数日の流れを追いにくいという具体的な困りごとから、スラログを作った意図へつないだ。個人名、顔写真、誇大表現、勝敗や設定を示唆する表現は追加していない。

## Visual QA比較

変更前は料金を同じ大きさの2カードで比較し、機能セクションも枠付きカードが連続していた。変更後は料金を「14日間／¥0 → 月額¥380」の1本の流れへまとめ、実画面を中心にした区切り線ベースの機能説明へ変更した。

- PC／モバイルのトップ全体を確認
- PC／モバイルの料金セクションを個別確認
- 320、390、768、1440pxで横overflowなし
- 料金の数値、補足、解約導線に欠け・重なりなし
- スクリーンショットは`artifacts/site-copy-audit/`へ保存（Git追跡対象外）
