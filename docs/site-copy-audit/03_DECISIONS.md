# 文言・情報設計の決定

1. サポート、プライバシー、利用規約はNKIS Worksの共通ページとして扱い、両サービス名を明記する。
2. トップのWebツール説明は総ゲーム数＋差枚から始まる中核機能を優先し、投資・回収や実IN／OUTは補助機能として前面に出さない。
3. 「計算結果」を基準語とし、「クイック」は画面表示から除く。
4. 「寄与」は内部概念に留め、画面では「押し上げ・押し下げ」と表す。
5. 基準との関係は「上回る／下回る」で表し、「好調／低調」の評価語を使わない。
6. 実績出玉率・基準差は入力値と計算式による算出、3枚掛け換算・交換条件を含む金額は前提付き参考値として区別する。
7. previewはnoindexかつcanonicalなし、productionは `SITE_ORIGIN` からcanonical・og:url・sitemapを生成する既存契約を維持する。
8. 日本語中の区切りは原則「／」とし、負数表示は「−」を維持する。
9. active状態は `aria-current="page"` で示し、見た目でも下線を付ける。
10. 免責は価値説明の後、誤認が生じる箇所に限定して置く。
