## 比較案A — 横レール（非推奨）

```text
┌───────────── viewport ─────────────┐
│ [100% +500] [103% +140] [105% −100] →
│  ●──────────○──────────○             │

```

3件でも320px/200%ズームで一部が隠れ、スワイプ可能性の説明が必要。補助図以外には使わない。

## 200%ズーム時

2列を強制せず1列へ折り返す。比較行は `基準 → 期待差枚 → 実績との差` の順で行内改行し、値を省略しない。広告が将来有効でも横固定幅を持たせない。
