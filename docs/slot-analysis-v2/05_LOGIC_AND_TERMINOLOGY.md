# 計算ロジックと用語

## 記号

| 記号  | 意味                        | 単位 |
| ----- | --------------------------- | ---- |
| `G`   | 総ゲーム数                  | G    |
| `N`   | 差枚（最終枚数 − 投入相当） | 枚   |
| `I`   | IN                          | 枚   |
| `O`   | OUT                         | 枚   |
| `R`   | 出玉率                      | %    |
| `B`   | 比較基準率                  | %    |
| `G_t` | 目標総ゲーム数              | G    |
| `R_t` | 目標総出玉率                | %    |

内部計算は整数または有理数を使い、浮動小数点の表示誤差を避ける。表示丸めは既存と同じhalf-away-from-zeroを原則とする。

## クイック実績分析

スロットは1ゲーム3枚投入を**想定**する。

```text
想定IN I = G × 3
想定OUT O = I + N
実績出玉率 R = O ÷ I × 100
1,000Gあたり差枚 = N ÷ G × 1,000
```

例: `G=4,000`, `N=+500`

```text
I = 12,000枚
O = 12,500枚
R = 104.1666...% → 104.2%
N/1,000G = +125枚
```

### 表示精度

- 実績出玉率: 小数1桁。
- 1,000Gあたり差枚: 小数1桁まで必要時表示。整数なら整数。
- IN/OUT、基準差枚: 整数枚。
- 内部値: 丸め前の分数を保持。

## 基準比較

基準 `B` の期待差枚:

```text
基準OUT = I × B ÷ 100
基準差枚 E_B = 基準OUT − I = I × (B − 100) ÷ 100
基準との差 D_B = N − E_B
```

4,000G/+500枚では:

| 基準 | 基準差枚 | 実績との差 |
| ---- | -------: | ---------: |
| 100% |      0枚 |     +500枚 |
| 103% |   +360枚 |     +140枚 |
| 105% |   +600枚 |     −100枚 |

厳密な有理数で正なら「基準を上回る」、負なら「基準を下回る」、0なら「基準通り」。表示差枚はhalf-away-from-zeroで整数化する。表示が0枚でも厳密差が0でなければ、`差は1枚未満（上回る）` または `差は1枚未満（下回る）` とし、`基準通り`にはしない。これは設定や将来結果の判定ではない。

クイック比較も区間比較も初期選択は置かない。選択前に返すのは上回る/下回る/基準通りという計算事実だけ。選択後だけ、選んだ基準についての要約や区間ラベルを返す。

## 100枚変化の感度

同じGで差枚が100枚変わったときの出玉率差:

```text
感度 = 100 ÷ (G × 3) × 100 percentage points
```

4,000Gでは約 `0.8333ポイント`。表示は補足情報として `約0.8ポイント/100枚`。短いGほど振れが大きいことを説明し、信頼区間や確率とは呼ばない。

## 目標逆算

現在 `G,N` から、目標総G `G_t`、目標率 `R_t` に到達する数学上の必要条件を求める。

```text
目標総IN I_t = G_t × 3
目標総OUT O_t = I_t × R_t ÷ 100
目標総差枚 N_t = O_t − I_t
残りG G_r = G_t − G
必要差枚（厳密値） N_r = N_t − N
必要差枚（整数境界） N_min = ceil(N_r)
必要残区間OUT O_r = G_r × 3 + N_r
整数境界の必要残区間率 R_r = (G_r × 3 + N_min) ÷ (G_r × 3) × 100
```

例: 4,000G/+500枚から5,000G時点で100%:

```text
残り1,000G
目標総差枚 0枚
−500枚までなら5,000G時点で100%を維持
境界となる出玉率 83.3%以上
```

表示文は整数境界の符号で分ける。

| 整数境界 | 状態code                 | 主文                      |
| -------- | ------------------------ | ------------------------- |
| 正       | `must_gain`              | `あと+N枚必要`            |
| 0        | `no_net_change_required` | `差枚0枚以上で目標に到達` |
| 負       | `can_lose_up_to`         | `−N枚までなら目標を維持`  |

必要残区間OUTが負になる場合は、実行可能な最小OUTである0枚へ境界を丸め、必要残区間率を0%とする。状態は `any_nonnegative_out_suffices`。`−500枚`のような負値は「あと必要」ではなく許容できる減少幅であり、損失推奨ではない。

## 区間直接入力

区間 `i` の値 `g_i,n_i`:

```text
合計G = Σg_i
合計差枚 = Σn_i
区間率 = (3g_i + n_i) ÷ 3g_i × 100
合計率 = (3Σg_i + Σn_i) ÷ 3Σg_i × 100
```

### 基準からの区間寄与

基準 `B` に対する区間差:

```text
区間期待差枚 e_i = 3g_i × (B − 100) ÷ 100
区間寄与 c_i = n_i − e_i
```

`c_i>0` は「基準に対して押し上げ」、`c_i<0` は「押し下げ」。全体寄与は `Σc_i` と一致する。実績差枚そのものの正負と混同しない。

## 累積地点入力

地点 `i` の累積値 `G_i,N_i` から:

```text
g_i = G_i − G_(i−1)
n_i = N_i − N_(i−1)
```

先頭の基準地点は `0G/0枚` に限定せず、任意の開始G/差枚を許す。たとえば `2,000G/+300枚` から始められる。`G_i` は厳密増加。累積差枚は増減可能。直接区間と累積地点を同じ表で混ぜない。

## 最大下落・最大回復

累積差枚列 `N_0...N_k` に対するエンドポイント指標:

```text
最大下落 = max_{j>i}(N_i − N_j), ただし N_i はj以前の最高値
最大回復 = max_{k>j>i}(N_k − N_j), ただし N_i は下落前の最高値、N_j はその後の最安値
```

- 最大下落は局所最高点から後続最低点までの最大減少枚数。
- 最大回復は、一度下落が始まった後の局所最低点から、後続地点までの最大増加枚数。開始点から最初の上昇は回復に含めない。
- 区間内の軌跡は分からないため、入力地点間のエンドポイントだけで計算する。
- 「ドローダウン」は補助語に留め、UI主語は「入力地点間の最大下落」。
- UIの回復ラベルは「下落後の最大回復」。下落が一度もなければ回復量は0、開始/終了indexは未定義とする。
- 同じ最大値が複数ある場合は、最大下落では最も早いpeak、次に最も早いtroughを採用する。最大回復では最も早いtrough、次に最も早いrecovery endを採用する。

## 実IN/OUT

実測値がある場合:

```text
実差枚 = actualOut − actualIn
実績率 = actualOut ÷ actualIn × 100
```

クイック分析の `G×3` は想定IN、こちらは実IN。両者を同じ結果カードに混在させない。

## 投資・回収

```text
理論交換額 = 交換対象枚数 × 交換率（円/枚）
交換単位適用枚数 = floor(対象枚数 ÷ 単位枚数) × 単位枚数
交換額 = 単位適用枚数 × 交換率
端数 = 対象枚数 − 単位適用枚数
収支 = 交換額 + 交換済現金 − 現金投資
現金回収率 = 現金回収 ÷ 現金投資 × 100
```

貯メダル価値を含める「総回収率」と、現金だけの「現金回収率」を分ける。交換率の入力単位を円/枚に固定し、枚/1000円表記は補助変換する。

## 用語規約

| 使う                 | 避ける                 | 理由                       |
| -------------------- | ---------------------- | -------------------------- |
| 実績出玉率           | 設定○相当、真の機械割  | 観測値からの計算であるため |
| 想定IN/OUT           | 実IN/OUT               | 3枚/G仮定を明確にする      |
| 基準を上回る/下回る  | ヒキ強/ヒキ弱、勝ち台  | 中立性                     |
| 必要条件             | 期待、予測、達成できる | 未来を保証しない           |
| 入力地点間の最大下落 | 最大損失               | 金銭損失とは限らない       |
| 区間寄与             | 原因、要因             | 因果を推定しない           |

## エラーと警告

- error: 計算不能（G≤0、非整数、OUT<0、目標G≤現在G、累積G非増加）。
- warning: 計算可能だが誤解可能（非常に短いG、極端な率、交換単位の端数）。
- info: 前提（1G=3枚、想定値、地点間のみ、保存しない）。

エラーはフィールド近傍と要約に表示し、警告は結果を隠さない。入力値を含む内部例外をconsoleへ出さない。
