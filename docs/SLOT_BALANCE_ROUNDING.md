# スロバランス 端数処理

## 1. 原則

内部値は約分済み有理数で保持し、表示時だけ丸める。回収ラインの不足防止や交換単位の反映は表示装飾ではなく計算規則なので、指定された方向へ明示的に切り上げ・切り捨てる。

## 2. 四捨五入

四捨五入は`round half away from zero`とする。ちょうど半分の場合、正数は正方向、負数は負方向へ丸める。

例：

- `1.24`を小数1桁 → `1.2`
- `1.25`を小数1桁 → `1.3`
- `-1.24`を小数1桁 → `-1.2`
- `-1.25`を小数1桁 → `-1.3`

JavaScriptの`Math.round`へ直接依存しない。分子の絶対値へ半分判定を行い、最後に符号を戻す。

## 3. 表示規則

| 項目 | 規則 |
|---|---|
| 差枚ベース出玉率 | 小数第1位、half away from zero |
| 実IN/OUT出玉率 | 小数第1位、half away from zero |
| 回収率 | 小数第1位、half away from zero |
| 1,000Gあたり差枚 | 1枚単位、half away from zero |
| 差枚 | 1枚単位、入力整数を維持 |
| 必要回収枚数 | 不足しないよう数学的ceil |
| 理論交換額の表示 | 1円未満をfloor |
| 交換単位反映額 | 単位へfloor |
| 現金差額 | 1円単位 |
| 貯メダル込み価値差額 | 内部有理数、表示は1円へhalf away from zero |
| コイン持ち | 小数第1位、half away from zero |
| 貸出・交換枚数 | 入力した10進精度を有理数として保持 |

## 4. floorとceil

floorは負の無限大方向、ceilは正の無限大方向とする。交換見込額は非負入力を前提とするが、utility自体は負数でも数学的定義どおり動作する。

交換単位ありの見込額は理論値を超えず、理論値との差は交換単位未満となる。回収必要枚数は円換算した必要額を満たす最小整数枚数とする。

## 5. シリアライズ

正確な分数は`{ numerator: string, denominator: string }`として結果へ格納する。JSONで扱えない`bigint`を公開結果へ直接含めない。併せて説明・表示用の`approximate`と`display`を返す。
